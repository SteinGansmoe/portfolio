# Icon sources

The HTML, CSS, Next.js, PostgreSQL and Vercel SVGs were downloaded unchanged
from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons):

- `html5/html5-original.svg` → `html5.svg`
- `css3/css3-original.svg` → `css3.svg`
- `nextjs/nextjs-original.svg` → `nextjs.svg`
- `postgresql/postgresql-original.svg` → `postgresql.svg`
- `vercel/vercel-original.svg` → `vercel.svg`

Devicon's MIT license is included in `LICENSE.devicon`. Next.js and Vercel
receive a CSS inversion in the technology metadata for visibility on dark surfaces.

`rest-api.svg` (request/response arrows) and `ai-development.svg` (code and a
sparkle) are project-authored neutral symbols, not vendor logos. They use the
portfolio's muted foreground color and the same 24px display size as other skills.
